Cloud Sync

Optional multi-device sync. Core sessions still work locally without an account.

Your sync account

What gets synced

Cloud Sync sends up to 10 recent manual sessions, newest first, stopping before the next whole session would exceed 300 URLs. Sessions are never split; the rest and automatic saves stay local. Cloud snapshots also have a 512 KB limit.

10Manually Saved300URLs512 KBSnapshot

After local changes, Cloud Sync pushes automatically after about 10 minutes and also tries to sync when the browser closes. Push writes are rate-limited by the cloud service.

Diagnostics

Check local storage and download a report to help troubleshoot problems.

Local storage

At 90% of the storage limit, older or identical automatic saves are removed until usage is below 85%, where possible. Manual sessions and the latest scheduled and exit saves are kept.

Logs and diagnostic report

Includes the latest 200 events, session counts and sizes, extension and browser versions, storage usage, and Auto Save and Cloud Sync status. Logs start with this update and stay on this device.

The anonymized report excludes URLs, account details and tokens. Session names and free-text error messages are replaced with placeholders.

Full logs can contain session names and URLs from technical errors. Review the file before sharing it. This report is not a session backup.
